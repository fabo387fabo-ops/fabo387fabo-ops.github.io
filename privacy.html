Privacy Policy

The Pilos · Pilo Uploader · Last updated 15 November 2026

This policy covers Pilo Uploader, a private tool used by the owner of the YouTube channel The Pilos to upload the channel's own videos, and this website.

What Pilo Uploader does

Pilo Uploader uses the YouTube API Services to upload videos, titles, descriptions, tags and thumbnails to The Pilos channel. Only the channel owner signs in to it. It is not offered to the public, and it does not access, collect or store information about anyone else.

Information it uses

When the channel owner signs in with Google, Pilo Uploader receives an access token limited to uploading videos to that channel (scope youtube.upload). The token is stored as an encrypted secret in the owner's private build system and is used only to upload the owner's videos. Pilo Uploader does not read, sell or share any personal data, and it does not use cookies or analytics.

This website

This website does not collect personal information, set cookies or use analytics. It is hosted on GitHub Pages, and GitHub may keep standard server logs as described in the GitHub Privacy Statement.

YouTube and Google

Pilo Uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. You can remove Pilo Uploader's access to a Google account at any time at myaccount.google.com/permissions.

Contact

Questions about this policy can be sent through the contact details on The Pilos channel page.
